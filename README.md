# RYVONEXA '26

National Level Technical & Non-Technical Symposium organized by the Department of Computer Science & Engineering.

## 🚀 Quick Start

### Frontend (Client)
```bash
cd client
npm install
npm run dev
```

### Build for Production
```bash
npm run build --prefix client
```

## 🌐 Deployment
This project is configured for seamless one-click deployment on [Vercel](https://vercel.com).
